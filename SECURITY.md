# Security Policy

## Supported Versions

The development team actively maintains and releases security patches for the following versions:

| Version | Supported | Status |
| :--- | :---: | :--- |
| Odoo 20.0 | :white_check_mark: | Primary development target |
| Odoo 18.0 | :white_check_mark: | Active support |
| < 18.0 | :x: | End of Life / Community backport only |

---

## Reporting a Vulnerability

The maintainers of **Odoo Financial Suite** take software security seriously. If you identify a security issue, vulnerability, or potential exploit:

1. **Do not create a public issue:** Please refrain from disclosing vulnerabilities in publicly accessible issue trackers or forums.
2. **Contact the Security Team:** Send an encrypted or direct disclosure email to `billing@ppti.me` (or submit a confidential advisory via GitHub Security Advisories).
3. **Information to Include:**
   * A detailed description of the vulnerability.
   * Steps to reproduce the issue (including sample payloads, screenshots, or configuration files).
   * Affected module name(s) and Odoo versions.
   * Proposed mitigation or fix, if available.

---

## Response Timeline

* **Acknowledgment:** Within 48 hours of receiving the initial report.
* **Assessment & Verification:** Within 5 business days.
* **Fix & Release:** Critical security patches will be published as high-priority hotfix releases with appropriate attribution to the reporter.
